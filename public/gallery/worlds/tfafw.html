The First and Final World

The First and Final World is my current fantasy worldbuilding project. It was inspired/sparked by this amazing adventure module by Rowan, Rook, and Decard. It has since spiraled off into something that is only very slightly related to the original setting. It does still get it's namesake from it though. And no I don't really have an in-world explaination for what it means. Is it really the first and final world? Probably not! But it sounds cool.

This world has become my depositry for all ideas fantasy. Originally it had a bit of a steampunk-y vibe, but at this point it is solidly weird medieval. I've pulled ideas from Cursa and a few other worlbuilding projects that never got fleshed out enough to be mentioned here.
